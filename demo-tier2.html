🔧 Technical Details

Wasm Color Mapping

Uses a minimal 50-line WebAssembly module for fast palette index → RGBA32 conversion. Processes pixels in row-sized chunks to maintain streaming behavior while leveraging hardware acceleration. Expected 1.6-2x speedup on modern hardware.

Zero-Copy Canvas Display

Creates ImageData directly from Uint32Array backing store, eliminating one memory copy. Reuses ImageData objects when possible for maximum efficiency. Only one unavoidable copy remains (into canvas buffer).

Lazy Disposal Animation

Skips disposal operations when the next frame fully covers the previous frame with opaque pixels. Common in stickers and simple animations. Can save significant bandwidth and computation.
