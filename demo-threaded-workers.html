Parallel frame decode when WebAssembly threads aren't available

Worker Pool Architecture

Each worker maintains its own WebAssembly instance and LZW decode tables, enabling true parallelism across frames.

// Main thread - distribute frames across worker pool const pool = Array.from({length: n}, () => new Worker('decoder-worker.js')); function decodeAsync(frameIndex) { const worker = pool[next++ % n]; return worker.postMessage({ gifData: gifData.slice(), // Transferable buffer frameIndex }, [gifData.buffer]); } // Worker - dedicated Wasm instance per worker self.onmessage = ({data}) => { const pixels = decodeFrame(data); // Per-worker Wasm + LZW tables self.postMessage({pixels}, [pixels.buffer]); // Transfer back to main };

Implementation Guide

1. Initialize Worker Pool

const reader = new wtfgif.GifReader(gifData); // Initialize threaded worker pool (alternative to Wasm threads) const poolInitialized = await reader.initWorkerPool({ workerCount: navigator.hardwareConcurrency, // Use all CPU cores maxQueueSize: 100 }); console.log('Worker pool ready:', poolInitialized);

2. Parallel Frame Decode

// Decode multiple frames in parallel const frameIndices = [0, 1, 2, 3, 4, 5, 6, 7]; const results = await reader.framePixelsThreadedPool(frameIndices); // Results arrive as workers complete results.forEach((frame, i) => { console.log(`Frame ${frameIndices[i]}: ${frame.pixels.length} pixels`); displayFrame(frame.pixels, frame.delay); });

3. Load-Balanced Single Frame

// Single frame with automatic load balancing const pixels = await reader.framePixelsWorkerPool(frameIndex); // Worker pool automatically selects least busy worker const stats = reader.getWorkerPoolStats(); console.log('Worker utilization:', stats.workerUtilization);

4. Performance Monitoring

// Monitor worker pool performance const stats = reader.getWorkerPoolStats(); console.log({ activeWorkers: stats.activeWorkers, completedJobs: stats.completedJobs, avgDecodeTime: stats.avgDecodeTime + 'ms', queuedRequests: stats.queuedRequests }); // Cleanup when done await reader.cleanupWorkerPool();
