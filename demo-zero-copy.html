Persistent buffer allocation with zero-copy canvas presentation. Buffer allocated once, reused for all frames.

// Once const outPtr = wasm.malloc(w * h * 4); const rgbaU8 = new Uint8ClampedArray(wasm.memory.buffer, outPtr, w*h*4); const image = new ImageData(rgbaU8, w, h); // shares the same buffer // Each frame decode_rgba(ptrGif, gifLen, i, outPtr, w*h); ctx.putImageData(image, 0, 0); // no .set(), no GC

Implementation Guide

1. WebAssembly Zero-Copy Pattern

const reader = new wtfgif.GifReader(gifData); await reader.initWasm(); const canvas = document.getElementById('myCanvas'); const ctx = canvas.getContext('2d'); // Zero-copy presentation - no memory allocation per frame reader.frameImageDataZeroCopy(frameIndex, ctx);

2. GPU ImageBitmap Pattern

const reader = new wtfgif.GifReader(gifData); await reader.initGPU(); // Create ImageBitmap for efficient transfer/drawing const bitmap = await reader.frameImageBitmapGPU(frameIndex); if (bitmap) { ctx.drawImage(bitmap, 0, 0); bitmap.close(); // release GPU memory }

3. Worker Transfer Pattern

// In worker const reader = new wtfgif.GifReader(gifData); await reader.initGPU(); const bitmap = await reader.frameTransferBitmapGPU(frameIndex); if (bitmap) { // Transfer ownership to main thread postMessage({ type: 'frame', bitmap }, [bitmap]); } // In main thread worker.onmessage = (e) => { if (e.data.type === 'frame') { ctx.drawImage(e.data.bitmap, 0, 0); e.data.bitmap.close(); } };
